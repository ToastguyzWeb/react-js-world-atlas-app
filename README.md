# 🌍 World Atlas - React App
A comprehensive **world atlas application** showcasing countries and their detailed facts. Built with **React** + **Vite**, **React Router DOM**, **Bootstrap**, and **REST Countries API**.
<br/>
Explore the world through an interactive and informative interface that displays comprehensive information about all countries. Users can **browse, search, and sort** through countries, view detailed country profiles with facts, statistics, and geographical information. Perfect for students, researchers, or anyone curious about world geography and country data.
<br/>

## 🌟 Features
- 🌎 **Complete Country Database** - Data for multiple countries
- 🔍 **Advanced Search** - Find countries by name, region, or capital
- 📊 **Smart Sorting** - Sort by asc and desc
- 📱 **Fully Responsive** design with Bootstrap components
- 🗺️ **Detailed Country Pages** - Comprehensive facts and statistics
- 🧭 **Multi-page Navigation** with React Router DOM
- 📞 **Contact Form** for user inquiries and feedback
- ⚡ **Real-time Data** from REST Countries API
- 🎨 **Clean Bootstrap UI** with modern styling

## 🛠️ Setup Instructions

1. **Clone this repository:**
   ```bash
   git clone https://github.com/ToastguyzWeb/react-js-world-atlas-app.git
   cd react-js-world-atlas-app
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Start the Development Server**
   ```bash
   npm run dev
   ```

4. **Build for Production**
   ```bash
   npm run build
   ```
